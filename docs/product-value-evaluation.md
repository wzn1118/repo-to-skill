## Parameter evidence

Discovery 1.4 records explicit literal `required`, `nargs`, `action`, `is_flag`, `multiple`, `count`,
`default`, `choices` and recognized built-in type declarations where available. Every field belongs
to the existing path-owned option Claim and source witness. Omitted/dynamic values remain unknown;
no framework defaults, effective runtime values, positional arguments or mutual-exclusion semantics
are invented. Parser overrides and callbacks can change behavior after declaration.

This boundary follows the [Python argparse keyword contract](https://docs.python.org/3.12/library/argparse.html#the-add-argument-method)
and [Click option contract](https://click.palletsprojects.com/en/stable/options/). Their documentation
does not substitute for evidence from a pinned target source. Untrusted source descriptions are not
used as planner instructions. Potential secret defaults, absolute local paths and unsafe literal
strings are omitted. Legacy 1.2/1.3 imports preserve unknown fields and remain review-required.

参数语义目前表示“源码显式声明”，不能冒充最终运行行为。默认值存在与默认值为 null 分开处理；
未提取到 required 也不能解释为可选。生成引用按命令路径列出这些字段，并保留未知边界。

## Thirty reference tasks

[`cli-value-v2.json`](../benchmark/tasks/cli-value-v2.json) freezes ten tasks per tool with source SHA,
initial files, user goal, reference argv, expected exit and independent file/output assertions.
No help/version checks count as tasks. Tasks include both successful operations and intentional
rejections, so the latter must report the required failure and preserve files.

- Black: file/code formatting, check, diff, exclusions, quote/config handling, invalid syntax, idempotence.
- pre-commit: valid and invalid config/manifests, stage/language/regex errors, generated sample validation.
- Cookiecutter: local templates, context overrides, nested files, output directories, overwrite and refusal.

These are a development cohort selected for feasible static support, not representative samples or
held-out tests. Reference solutions are agent-authored; they are not generated by the Planner and are
never inserted into generated Skills. A passing reference validates task setup and the oracle, not
Skill utility. Hashes bind taskset, runner, worker, wheels, image and each source lock. All attempts
remain versioned. Oracle mutation tests reject wrong output even when the process exits successfully.

```bash
python scripts/run_task_oracles.py --snapshots /data/snapshots --wheels /data/wheels \
  --taskset benchmark/tasks/cli-value-v2.json \
  --image sha256:<installed-image-id> --output benchmark/task-runs/new-attempt.json
# Review the preview, then explicitly add --execute.
```

Execution uses cached binary wheels in a non-root, offline container with read-only source and
bounded CPU/memory/processes/time. Wheels provide dependencies and distribution metadata; an import
origin check requires the main package to come from `/source`. Metadata versions can differ from the
pinned source and are recorded separately. This is not a source-built release qualification.

[Measured reference validation](../benchmark/task-runs/2026-09-16-cli-value-v1/README.md): v1 passed
29/30; v2 corrects only the casing of Black's invalid-syntax stderr anchor and passes 30/30 after a
full rerun. The first attempt and both task versions remain intact. No Agent experiment was run.

## Three-arm experiment: not yet executed

Freeze one exact model/version, temperature, tool environment and budget before the first trial.
Run each of the same 30 tasks in fresh sessions under three conditions:

| Arm | Material available to the Agent |
| --- | --- |
| Documentation | Pinned official CLI docs, no Skill |
| Generated | Compiler-generated Skill and its references |
| Human | Independently human-authored/reviewed Skill |

All arms receive the same task input and execution tools. Keep gold argv and oracle implementation
out of model context; expose only the task's required observable result. Randomize arm order and use
five paired repetitions: 450 trials. Freeze a proposed cap of 20 tool calls, 8,000 output tokens and
180 seconds per trial; model selection and paid usage still require concrete configuration/authorization.

Record every attempt: success by oracle, invalid options/values, source-version mismatch, wall time,
input/output tokens, budget exhaustion and infrastructure failures. Do not retry failures out of the
denominator. Publish raw trajectories after secret screening and paired differences with uncertainty;
resample at task level to avoid treating repeated trials as independent tasks. Pre-register thresholds
before evaluating, and do not claim improvement until measured. A machine-authored Skill must never
be labelled human-authored. Human sign-off and model trials are currently absent.

固定模型、预算和工具权限后再做三组对照。标准解法通过不等于 Agent 通过；人工组必须确实由人整理
并签核，不能用另一个模型生成的内容冒充。当前没有模型试验，也没有提升比例。
